# NIRVAAH — SVG Brand Kit v2

This kit was rebuilt from the actual approved logo image in the conversation, rather than approximating the infinity symbol from scratch.

## Assets
- `nirvaah-primary-horizontal.svg` — primary horizontal lockup, including English and Devanagari wordmarks.
- `nirvaah-primary-dark.svg` — primary lockup for dark surfaces.
- `nirvaah-lockup-compact.svg` — compact symbol + English wordmark.
- `nirvaah-symbol.svg` — standalone symbol in cobalt.
- `nirvaah-symbol-black.svg` / `nirvaah-symbol-white.svg` — monochrome symbol variants.
- `nirvaah-app-icon.svg` — square app icon.
- `nirvaah-wordmark.svg` — editable English wordmark.
- `nirvaah-monochrome.svg` — single-colour horizontal lockup.

## Palette
- Electric cobalt: `#071EF8`
- Near-black ink: `#111820`
- Accent orange: `#FF7A1A`
- Warm ivory: `#F8F6F2`
- Secondary slate: `#68717D`

## Typography
- English: Space Grotesk, weight 700 for the wordmark.
- Devanagari: Noto Sans Devanagari, weight 500.
- Tagline: Space Grotesk, weight 600 with tracked capitals.

SVG text remains editable and references local/system fonts. For consistent rendering, install Space Grotesk and Noto Sans Devanagari. For production print or handoff, convert text to outlines in a vector editor.

## Important
The infinity symbol is a traced vector silhouette extracted from the approved logo artwork. It is now a true scalable SVG path, not an embedded PNG.
